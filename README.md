# Dra. Rosalina Arimitsu

Landing page responsiva com contato pelo WhatsApp, movimentos automáticos e ícones vetoriais.

## Abrir o site

Abra `index.html` no navegador. O arquivo contém estilos, scripts e imagens incorporados. Google Fonts e o mapa utilizam conexão externa.

## Código modular

`codigo-fonte.zip` contém a versão editável em HTML, CSS, JavaScript e assets. As folhas antigas são histórico; a página carrega somente `site.css` e `app.js`.

## Publicar na Vercel

Importe este repositório, escolha **Other** como framework e deixe os comandos de build e instalação vazios. A pasta raiz contém o `index.html` pronto para servir.
